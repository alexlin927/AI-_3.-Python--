Python 第三單元｜GitHub Pages 網路版（16:9，44頁）

使用方式：
1. 將本 ZIP 解壓縮。
2. 將 index.html、data.js 與 slides 資料夾上傳到 GitHub repository 根目錄。
3. Settings → Pages → Deploy from a branch → 選擇實際分支 main 或 master、/(root) → Save。
4. 開啟 GitHub Pages 提供的網站網址即可觀看。

注意：全部檔案必須保留相對目錄結構；不要只上傳 index.html。
講稿取自使用者提供的 PowerPoint 備忘稿，並非另行改寫。
